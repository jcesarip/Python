Cómo funcionan las funciones type() y isinstance()

###TYPE()
Para ver qué tipo dato tiene asignadoo una variable, puedes usar la función type() así:

developer = 'Devin'
print(type(developer)) # <class 'str'>

Si no proporcionas ningún argumento a la función type(), recibirás el siguiente mensaje de error:
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: type() takes 1 or 3 arguments

Aquí están los tipos de datos que has aprendido hasta ahora, junto con lo que la función type() imprime para cada uno

my_integer_var = 10
print(type(my_integer_var))  # <class 'int'>

my_float_var = 4.50
print(type(my_float_var))  # <class 'float'>

my_string_var = 'hello'
print(type(my_string_var))  # <class 'str'>

my_boolean_var = True
print(type(my_boolean_var))  # <class 'bool'>

###ISINSTANCE()
verificar que una variable en particular sea de un tipo específico antes de realizar operaciones sobre ella. Aquí es donde la función isinstance() resulta útil.

account_balance = '12'
isinstance(account_balance, int) # False

La función isinstance() también te permite verificar múltiples tipos a la vez.

account_balance = 12
isinstance(account_balance, (int, float)) # True
