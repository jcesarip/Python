¿Qué son los valores de verdad y falsedad, y cómo funcionan los operadores booleanos y el cortocircuito?

Si trabajas con sentencias condicionales más complejas, puedes usar los operadores and y or de not Python.

#### Valores truey y falsy
En Python, cada valor tiene un valor booleano inherente, o un sentido integrado de si debe tratarse como Trueo Falseen un contexto lógico. Muchos valores se consideran veraces , lo que significa que se tratan como Trueen un contexto lógico. Otros son falsos , lo que significa que se evalúan como False.

Aquí hay unos pocos valores falsos:

-False
-Entero 0
-Flotante 0.0
-Cadenas vacías ""

Otros valores, como números distintos de cero y cadenas no vacías, son Truthy.
Verificar si un valor es verdadero o falso, puedes usar la función incorporada bool().

Ejemplo:
print(bool(False)) # False
print(bool(0))  # False
print(bool('')) # False

print(bool(True)) # True
print(bool(1)) # True
print(bool('Hello')) # True


Operadores booleanos
Operadores booleanos, que también se conocen como operadores lógicos. Estos son operadores especiales que te permiten combinar múltiples expresiones para crear una lógica de toma de decisiones más compleja en tu código.

Hay tres operadores booleanos en Python: and, or y not.

### El operador AND
El operador and toma dos operandos y devuelve el primer operando si es un valor falso; en caso contrario, devuelve el segundo operando. Ambos operandos deben ser valores veraces para que una expresión resulte en un valor veraz.

Ejemplo:
is_citizen = True
age = 25
print(is_citizen and age) # 25

número 25 se imprime en la terminal porque el operador andevaluará el segundo operando si el primer operando es True. El operador andse conoce como un operador de cortocircuito. El cortocircuito significa que Python verifica los valores de izquierda a derecha y se detiene tan pronto como determina el resultado final.

A menudo usarás and dentro de sentencias ifpara verificar si se cumplen múltiples condiciones. Aquí te mostramos cómo puedes refactorizar el ejemplo anterior para usar el operador anden lugar de sentencias if anidadas.

Ejemplo
is_citizen = True
age = 25
if is_citizen and age >= 18:
    print('You are eligible to vote') # You are eligible to vote
else:
    print('You are not eligible to vote')

#### El operador OR
Este operador devuelve el primer operando si es un valor verdadero; en caso contrario, devuelve el segundo operando. Una expresión con or resulta en un valor Truthy si al menos un operando es Truthy. El operador or también es conocido como operador de cortocircuito.

Ejemplo:
age = 19
is_employed = False
print(age or is_employed) # 19

El código anterior imprimirá el número 19 porque el primer operando age es un valor veraz.

Si necesita verificar si al menos una expresión es veraz, puede usar el operador oren una condicional así:

Ejemplo:
age = 19
is_student = True
if age < 18 or is_student:
    print('You are eligible for a student discount') # You are eligible for a student discount
else:
    print('You are not eligible for a student discount')

En este caso, age < 18es False, pero is_studentes True. Dado que al menos una condición es verdadera, toda la expresión orse evalúa como Truey se imprime el mensaje de descuento en el bloque if.

#### El operador NOT
NOT toma un solo operando e invierte su valor booleano. Convierte valores Truthy en Falsey valores Falsy en True. A diferencia de los operadores anteriores que vimos, NOT siempre devuelve Trueo False.

Ejemplo:
print(not '') # True, because empty string is falsy
print(not 'Hello') # False, because non-empty string is truthy
print(not 0) # True, because 0 is falsy
print(not 1) # False, because 1 is truthy
print(not False) # True, because False is falsy
print(not True) # False, because True is truthy

Es común usar el operador noten condicionales para verificar si un valor es falso.

Ejemplo:
is_admin = False
if not is_admin:
    print('Access denied for non-administrators.') # Access denied for non-administrators.
else:
    print('Welcome, Administrator!')

Como is_admines False, not is_adminse evalúa como True. Por lo tanto, se imprimirá el mensaje Access denied for non-administrators..

Ahora que entiendes los valores de verdad y falsedad, los operadores and, ory not, y cómo funciona el cortocircuito, puedes escribir lógica condicional más flexible y legible.
