El corte de cadenas te permite extraer una porción de una cadena o trabajar solo con una parte específica de ella.

Ejemplos:
string[start:stop]

Si deseas extraer caracteres desde un cierto índice hasta otro, simplemente separa los índices start y stop con dos puntos:

Ejemplo:
my_str = 'Hello world'
print(my_str[1:4]) # ell

Ten en cuenta que el índice stop no es inclusivo, por lo que [1:4] solo extrae los caracteres desde el índice 1, y hasta, pero sin incluir, el carácter en el índice 4.

También puedes omitir los índices de start y stop, y Python predeterminadamente tomará 0 o el final de la cadena, respectivamente. Por ejemplo, esto es lo que ocurre si omites el índice de start

Ejemplo:
my_str = 'Hello world'
print(my_str[:7])  # Hello w

Esto extrae todo desde el índice 0 hasta (pero sin incluir) el carácter en el índice 7. Y esto es lo que sucede si omites el índice stop:

Ejemplo
my_str = 'Hello world'
print(my_str[8:])  # rld

Esto extrae todo desde el carácter en el índice 8 hasta el final de la cadena.

Ten en cuenta que cortar una cadena no modifica la cadena original

Ejemplo:

my_str = 'Hello world'
print(my_str[8:])  # rld
print(my_str)  # Hello world

También puedes omitir tanto los índices de start como de stop, lo que extraerá toda la cadena:

Ejemplo:
my_str = 'Hello world'
print(my_str[:])  # Hello world


Además de los índices start y stop, también existe un parámetro opcional step, que se usa para especificar el incremento entre cada índice en el slice.

Ejemplo:
string[start:stop:step]

En el ejemplo a continuación, la división comienza en el índice 0, se detiene antes del 11, y extrae cada segundo carácter:

Ejemplo:
my_str = 'Hello world'
print(my_str[0:11:2])  # Hlowrd

Un truco útil que puedes hacer con el parámetro step es invertir una cadena configurando step en -1 y dejando start y stop en blanco:

Ejemplo:
my_str = 'Hello world'
print(my_str[::-1]) # dlrow olleH
